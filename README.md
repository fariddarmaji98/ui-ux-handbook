# Handbook Orkestrator UI/UX

Handbook latihan praktik untuk developer frontend yang ingin mengarahkan AI membuat UI/UX yang rapi, punya hierarki, dan pas untuk penggunanya.

Isinya 14 modul (persiapan lab, slop, hierarki, spacing, tipografi, warna dan kontras, density, state dan hukum UX, design system untuk AI, brief desain, loop kritik, copywork, belajar dari designer, capstone) dan 3 lampiran (cek anti-slop, kamus instruksi, sumber belajar). Setiap modul berisi latihan interaktif di halaman, langkah praktik di project dengan prompt siap salin, checklist bukti lulus, dan kolom catatan.

## Cara pakai

Buka `index.html` di browser. Satu file, tanpa build dan tanpa dependensi selain Google Fonts.

Progres, catatan, dan token desain tersimpan otomatis di `localStorage` browser yang dipakai.
